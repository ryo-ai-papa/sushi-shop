# へい、らっしゃい！おすしやさん

[ゲームで遊ぶ](https://ryo-ai-papa.github.io/sushi-shop/)

小さな子どもがタップで遊べるお寿司屋さんゲームです。横向き推奨。時間制限・減点・広告・課金・ログインはありません。

ご飯をぎゅっ → ネタを選ぶ → へい、おまち！ 3人に届けるとシールが出ます。おたすけ・音の切り替え、注文の再読み上げ、選び直しができます。

## 音声クレジット

- お店の人：VOICEVOX:ずんだもん
- くま：VOICEVOX:雨晴はう
- うさぎ：VOICEVOX:四国めたん
- ねこ：VOICEVOX:春日部つむぎ

音声は生成済みのファイルを同梱しています。各音源の利用条件・出典は[音声について](./クレジット.html)をご覧ください。イラストは自作SVGです。

## 構成

HTML・CSS・JavaScriptと音声ファイルのみ。ビルド不要。index.htmlをブラウザーで開くか、静的ホスティングに配置できます。GitHub Pagesはmainブランチのルートから公開します。

実ブラウザーで3人への提供、ネタの選び直し、横画面3サイズを確認済み。iPhone実機は未確認です。
